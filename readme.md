# Т-скрипт

**Т-скрипт** — это интерпретируемый язык программирования с синтаксисом на русском языке, созданный для облегчения обучения программирования для русскоговорящей аудитории.

Проект ориентирован на простоту, читаемость и расширяемость, но в то же время настроен на функциональность.

Т-скрипт имеет полностью открытый исходный код, дающий полную прозрачность и возможность модифицировать любую часть кода.

---

## Особенности

- **Полностью русский синтаксис**

Ключевые слова, конструкции и стиль максимально приближены к естественному русскому языку.

- **Интерпретируемый**

Код выполняется напрямую без этапа компиляции.

- **Простой и понятный парсер**

Легко читать, модифицировать и расширять — идеально для учебных целей.

- **Чёткая модель выполнения**

Последовательный разбор → построение AST → интерпретация.

- **Модульная архитектура**

Лексер, парсер и интерпретатор логически разделены.

- **Расширяемость**

Можно легко добавить новые конструкции языка (циклы, функции, типы данных).
