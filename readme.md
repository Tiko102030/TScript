# TScript

TScript is an interpreted programming language with syntax in the Russian language, made for simplifying the learning process for beginner programmers who are not proficient in English.

The project is aiming for simplicity, readability and easy of future additions and improvements. At the same time, functionality is usefulness is an important consideration in development.

TScript is fully open source, giving all users full control and understanding of how the language works, as well as the ability to easily modify and improve the project. 

## Features 

- **Fully Russian syntax**

Keywords, constructions, and style are as close to natural Russian as possible.

- **Interpreted**

Code is executed directly without a compilation step.

- **Simple and intuitive parser**

Easy to read, modify, and extend — ideal for educational purposes.

- **Clear execution model**

Consistent parsing → building an AST → interpretation.

- **Modular architecture**

The lexer, parser, and interpreter are logically separated.

- **Extensibility**

It is easy to add new language constructs (loops, functions, and data types).

# Русский/Russian
# Т-скрипт

**Т-скрипт** — это интерпретируемый язык программирования с синтаксисом на русском языке, созданный для облегчения обучения программирования для русскоговорящей аудитории.

Проект ориентирован на простоту, читаемость и расширяемость, но в то же время настроен на функциональность.

Т-скрипт имеет полностью открытый исходный код, дающий полную прозрачность и возможность модифицировать любую часть кода.

---

## Особенности

- **Полностью русский синтаксис**

Ключевые слова, конструкции и стиль максимально приближены к естественному русскому языку.

- **Интерпретируемый**

Код выполняется напрямую без этапа компиляции.

- **Простой и понятный парсер**

Легко читать, модифицировать и расширять — идеально для учебных целей.

- **Чёткая модель выполнения**

Последовательный разбор → построение AST → интерпретация.

- **Модульная архитектура**

Лексер, парсер и интерпретатор логически разделены.

- **Расширяемость**

Можно легко добавить новые конструкции языка (циклы, функции, типы данных).
